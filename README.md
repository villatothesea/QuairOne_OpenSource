# QuairOne

**Grow your library, leaf by leaf.**
一页一叶，长成你的书园。

One quiet desk for everything you read — Markdown, text, PDF, EPUB and code — on your own disk. Each format is a plugin, downloaded inside the app.

一个安静的书桌装下你读的一切——Markdown、文本、PDF、EPUB 和代码——都在你自己的磁盘上。每种格式都是一个插件，在应用里下载。

---

## English

QuairOne is a Windows desktop reader and editor built around a plugin architecture: the host owns the window, panels, outline and shared behaviour; plugins own each format — each one downloaded inside the app, and unable to crash the host.

**Status:** the main program is being prepared for publication here — the codebase is being split so that everything published is open-source and free. This repository currently indexes the open-source components and takes your issues.

**Download:** the latest Windows installer and release notes are on the site — [quairone.pages.dev](https://quairone.pages.dev/). You can also file feedback straight from the site; it lands as an issue here.

**Open-source components:**

| Repository | What it is | Status |
| :-- | :-- | :-- |
| [PDFReader](https://github.com/villatothesea/PDFReader) | PDF reader plugin — pages rasterised with hayro (MIT/Apache-2.0) | Published |
| [EpubReader](https://github.com/villatothesea/EpubReader) | EPUB reader plugin — EPUB 2 and 3, DRM-free | Published |
| reader-sdk | the plugin contract — line-delimited JSON over stdio | Publishing next |
| QuairOne app | the host program itself | In split — first snapshot lands here |

**Issues:** bugs, wishes and feedback all live in [Issues](https://github.com/villatothesea/QuairOne_OpenSource/issues). The site’s Send button opens a pre-filled one for you.

**Licence:** MIT. Full third-party notices ship with the app.
